## ✨ Overview
A modern, responsive landing page for **ToDesktop**, a tool that converts any web app into a fully-native desktop application for **Windows, macOS, and Linux**.  
Built using **HTML + TailwindCSS + JavaScript**, this project follows clean design principles and a mobile-first approach.

## 📦 Installation & Setup

### 🔹 Method 1 — Simple Setup

```bash
git clone https://github.com/Ayush-Raghuwanshi-Dev/todesktop-landing-page.git
cd todesktop-landing-page
start index.html   # Windows
open index.html    # macOS
xdg-open index.html # Linux

```

### 🔹 Method 2 — Local Server

```bash
python -m http.server 8000
# OR
npx serve .

```
